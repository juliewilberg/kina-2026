# Kina 2026 🇨🇳

A travel page for our China trip in July 2026 — built to share our itinerary with family back home.

**Live site:** [juliewilberg.github.io/kina-2026](https://juliewilberg.github.io/kina-2026)

## What's on the page

- Full day-by-day itinerary across 8 destinations
- Interactive map with all stops along the route
- Hotel info with links for each location
- A few useful Mandarin phrases for the trip

## Route

Oslo → Beijing → Chongqing → Wulong → Furong → Zhangjiajie → Fenghuang → Dazhai/Longji → Guilin → Beijing → Oslo

## About

This was a small side project to experiment with [Claude](https://claude.ai) as a coding assistant — using AI to build something useful without writing much code manually. The result is a simple static site hosted on GitHub Pages.
